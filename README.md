# Arknights Desktop Pet

一个非官方的 Windows《明日方舟》桌宠项目，目前包含令、遥和阿米娅，以及 14 套 Spine 3.8 模型。

## 功能

- 透明置顶桌宠窗口
- 人物与皮肤切换
- 自动走动、拖动、重力下落和大小调节
- 单击互动、双击打开聊天
- 三名角色的中文固定台词原声，共 114 条
- Codex 或 DeepSeek 对话
- 每名角色独立的人物预设、参考语料、聊天记录和 Codex 线程
- 移动时保持输入框焦点；主动追随角色移动鼠标时仍可点击

## 直接使用

在 GitHub Releases 下载完整压缩包，解压后双击：

`启动明日方舟桌宠（无黑框）.vbs`

完整版已经包含 Electron 和所需依赖，不需要另外安装 Node.js。

## 从源码运行

需要 Node.js 18 或更高版本。

```powershell
npm install
npm start
```

Codex 对话会使用本机已有的 Codex/ChatGPT 登录状态。DeepSeek 需要在桌宠的“AI 对话设置”中填写 API Key；密钥使用 Windows 安全存储保存在本机，不会写入仓库。

## 基本操作

- 单击角色：播放互动动作和固定语音
- 双击角色：打开 AI 对话
- 左键拖动并松手：触发重力下落
- 鼠标滚轮：调整大小
- 右键角色：切换人物、皮肤、动作、自动走动、语音与 AI 设置
- `Esc`：关闭菜单、聊天或设置
- `Ctrl + Alt + Shift + A`：紧急退出
